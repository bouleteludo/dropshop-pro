# Dossier de soumission — thème « Lanterne » (Halloween)

Tout ce qu'il faut pour soumettre Lanterne au Theme Store de Shopify, dans
l'ordre. Coche au fur et à mesure.

| Dossier / fichier | À quoi il sert |
| --- | --- |
| `1-theme/lanterne.zip` | Le thème, à installer dans ta boutique de démo puis à envoyer à Shopify |
| `2-fiche-de-vente.md` | Tous les textes du formulaire de soumission, champ par champ, prêts à copier-coller |
| `3-site-documentation/` | Ta page de documentation et ton formulaire d'assistance, prêts à mettre en ligne |
| `4-boutique-demo/` | Les produits à importer dans la boutique de démo et le guide des captures d'écran |

## ⚠️ À faire avant d'envoyer le zip à Shopify

Le zip `1-theme/lanterne.zip` fonctionne déjà pour ta boutique de démo, mais
il ne peut pas encore être envoyé à Shopify :

- [ ] **L'image Halloween montre l'enseigne « BOO SHOP ».** Shopify refuse
  toute marque dans un thème vendu. Refais-la avec ChatGPT : « Recrée
  exactement cette image, même scène, même lumière, même cadrage, format
  16:9, mais l'enseigne doit être vierge : aucun texte, aucun nom, aucun
  logo. » Envoie-moi le résultat.
- [ ] **L'adresse de ta documentation** doit être écrite dans le thème
  (étape 3 ci-dessous). Envoie-moi l'adresse.

Dès que j'ai les deux, je te renvoie un `lanterne.zip` final, prêt pour
Shopify.

## Étape 1 — Compte Shopify Partner (10 min)

- [ ] Crée un compte gratuit sur **partners.shopify.com**.
- [ ] Choisis bien le nom : c'est le nom d'auteur affiché sur le Theme Store.
  Envoie-le-moi pour que je le mette dans le thème.

## Étape 2 — Boutique de démo (1 à 2 h)

- [ ] Dans le Partner Dashboard : **Boutiques → Ajouter une boutique →
  Boutique de développement**. Elle est gratuite.
- [ ] Dans cette boutique : **Boutique en ligne → Thèmes → Ajouter un thème →
  Importer un fichier zip** → `1-theme/lanterne.zip` → **Publier**.
- [ ] Importe les produits : **Produits → Importer** →
  `4-boutique-demo/produits-demo.csv`.
- [ ] Ajoute une photo à chaque produit. Utilise des photos dont tu as les
  droits, **sans texte incrusté**.
- [ ] Suis le reste de `4-boutique-demo/GUIDE.md` : collections, menus,
  pages, paiement de test, captures d'écran.

## Étape 3 — Documentation et assistance en ligne (15 min)

Le dossier `3-site-documentation` est un petit site déjà fait, avec la
documentation et le formulaire d'assistance.

- [ ] Va sur **app.netlify.com/drop** (gratuit, crée un compte).
- [ ] Glisse le dossier `3-site-documentation` dans la page. Netlify te donne
  une adresse publique, du type `https://xxxx.netlify.app`.
- [ ] Vérifie que le formulaire marche : envoie un message test depuis
  `/support.html`. Les messages arrivent dans ton compte Netlify (rubrique
  Forms), et tu peux y activer une notification par e-mail.
- [ ] Envoie-moi l'adresse.

## Étape 4 — Soumission (30 min)

- [ ] Partner Dashboard → **Themes** → **Submit a theme**.
- [ ] Envoie le `lanterne.zip` **final** (celui que je te renverrai), coche
  l'accord Partner, puis **Upload file**.
- [ ] Remplis le formulaire avec les textes de `2-fiche-de-vente.md`.
- [ ] Ajoute les 2 captures d'écran et le lien de la boutique de démo.
- [ ] **Submit.**

Shopify examine ensuite le thème en 5 étapes. Les réponses arrivent par
e-mail, en anglais ; envoie-les-moi et je t'aide à corriger.
